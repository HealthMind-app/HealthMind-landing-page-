# Sending photos and event records for the website

## Event records
Fill in `outreach-events-template.csv` (open it in Google Sheets or Excel), one row per event.
- `event_type`: outreach, summit, workshop, school-visit, or another single word.
- Dates as `YYYY-MM-DD`.
- `attendees_count`: only counted numbers (sign-in sheets, tickets), and say how you counted them.
- `quote_permission`: `yes` only if the person agreed to be quoted publicly.
- `publish_on_website`: `no` keeps the event private (still counted only if you say so).

## Photos
Put them in a shared Google Drive folder, one sub-folder per event, named like `photo_folder` in the sheet
(for example `2026-10-10-awareness-day`). Original quality, JPG or PNG.

### Consent (most important)
Being photographed at a mental-health event can reveal sensitive information about a person.
- Only send photos where **identifiable people agreed** to appear publicly.
- **Children**: written permission from a parent or guardian, or the school's documented consent process.
- Safer choices: crowds, people seen from behind, speakers on stage, activities, venues, banners.
- Unsure about a photo? Mark it and we will blur faces or leave it out.

### Per photo (optional, in a short text file in the folder)
A one-line caption, and the photographer's name if they should be credited.

## Partner logos
Logo files (SVG or PNG with a transparent background) and confirmation the partner agreed to be shown.
